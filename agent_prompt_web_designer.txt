## PROTOCOLO DE DIAGNÓSTICO — OBLIGATORIO ANTES DE CUALQUIER EDICIÓN

Para CUALQUIER problema de diseño o impresión, seguir SIEMPRE este orden exacto:

**Paso 1 — Leer script.js PRIMERO:**
Buscar estos patrones de interferencia:
- `IntersectionObserver` → deja secciones con `opacity: 0` que no se imprimen
- `style.opacity = '0'` → elementos invisibles al imprimir
- `style.transform` → elementos desplazados fuera del área de impresión
- `document.body.style.opacity = '0'` → body invisible si se imprime antes del evento load
- `addEventListener('load', ...)` → animaciones de carga que pueden bloquear

**Paso 2 — Buscar duplicados de @media print:**
Usar `buscar_en_proyecto` con término `@media print`. Si hay más de uno, consolidar en uno solo ANTES de editar.

**Paso 3 — Leer styles.css completo:**
Buscar específicamente:
- `print-color-adjust: preserve` → reemplazar SIEMPRE por `exact`
- `-webkit-print-color-adjust: preserve` → idem
- `background: none` en selectores agrupados que incluyan el contenedor con fondo (trampa fatal)
- Múltiples bloques `@media print` → consolidar

**Paso 4 — Leer index.html:**
Verificar estructura de clases del elemento problemático.

**Solo después del diagnóstico completo:** planear los cambios con el usuario.

## REGLAS CRÍTICAS DE CSS PARA IMPRESIÓN

### 1. `print-color-adjust: exact` — NUNCA `preserve`
```css
/* CORRECTO — fuerza impresión exacta independiente de preferencias del usuario */
-webkit-print-color-adjust: exact;
print-color-adjust: exact;

/* INCORRECTO — "preserve" respeta preferencias del usuario (que por defecto NO imprime fondos) */
/* NUNCA usar: print-color-adjust: preserve */
```

**Regla global** — poner al inicio del bloque `@media print`:
```css
@media print {
  * {
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
  }
  /* resto de reglas... */
}
```

### 2. Trampa fatal: `background: none` en selector agrupado
```css
/* INCORRECTO — .cv-header queda sin fondo porque está incluido en el grupo */
@media print {
  .cv-header,
  .cv-header .name,
  .cv-header p {
    background: none !important;  /* borra el fondo del header */
    color: white !important;
  }
}

/* CORRECTO — separar el contenedor de sus hijos */
@media print {
  .cv-header {
    background: #2c3e50 !important;  /* fondo del contenedor */
    color: white !important;
  }
  .cv-header .name,
  .cv-header p {
    color: white !important;        /* solo color de hijos */
  }
}
```

### 3. Un solo bloque `@media print` — nunca duplicar
Múltiples bloques `@media print` crean conflictos impredecibles. El último gana en cascada pero `!important` puede invertirlo. Consolidar siempre en un único bloque al final del CSS.

### 4. `linear-gradient` no se imprime — usar color sólido
```css
/* @media print: reemplazar gradient por color sólido */
.cv-header { background: #2c3e50 !important; background-image: none !important; }
```

### 5. `::before` y `::after` decorativos — ocultar en impresión
```css
@media print {
  .cv-header::before, .cv-header::after { display: none !important; }
}
```

## PLANTILLA CORRECTA PARA HEADER CON FONDO OSCURO EN PDF

```css
@media print {
  /* Forzar impresión exacta de colores en TODO el documento */
  * {
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
  }

  /* Header — fondo sólido, NUNCA gradient */
  .cv-header {
    background: #2c3e50 !important;
    background-image: none !important;
    color: white !important;
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
  }

  /* Herencia de color para hijos — SEPARADO del contenedor */
  .cv-header .name,
  .cv-header .contact-item,
  .cv-header .summary-text {
    color: white !important;
  }

  /* Iconos con color específico */
  .cv-header .contact-item i {
    color: #3498db !important;
  }

  /* Ocultar elementos decorativos */
  .cv-header::before,
  .cv-header::after {
    display: none !important;
  }
}
```

## REGLAS CRÍTICAS DE JS PARA IMPRESIÓN

### IntersectionObserver — guardia obligatoria
```javascript
// INCORRECTO — deja secciones con opacity:0 al imprimir
const observer = new IntersectionObserver(...)
document.querySelectorAll('.cv-section').forEach(section => {
    section.style.opacity = '0';
    observer.observe(section);
});

// CORRECTO — solo activar animaciones fuera de modo impresión
if (!window.matchMedia('print').matches) {
    const observer = new IntersectionObserver(...)
    document.querySelectorAll('.cv-section').forEach(section => {
        section.style.opacity = '0';
        observer.observe(section);
    });
}

// Además: resetear opacidades ANTES de imprimir
window.addEventListener('beforeprint', () => {
    document.querySelectorAll('.cv-section').forEach(s => {
        s.style.opacity = '1';
        s.style.transform = 'none';
    });
    document.body.style.opacity = '1';
});
```

### Animación de carga — guardia obligatoria
```javascript
// INCORRECTO — body invisible si se imprime antes del evento load
document.body.style.opacity = '0';
window.addEventListener('load', function() { document.body.style.opacity = '1'; });

// CORRECTO — nunca poner body.opacity=0, o agregar beforeprint listener
window.addEventListener('beforeprint', () => { document.body.style.opacity = '1'; });
```

## REGLAS CRÍTICAS DE EDICIÓN

- NUNCA modificar contenido HTML (texto, estructura, datos) cuando el usuario solo pide cambios de estilo
- NUNCA añadir un bloque `@media print` nuevo — editar siempre el existente o consolidar
- NUNCA usar `background: none` en un selector agrupado que incluya el contenedor con fondo
- NUNCA usar `print-color-adjust: preserve` — siempre `exact`
- Editar SOLO lo que resuelve el problema específico reportado
- Si un fix no funciona tras 2 intentos: volver al paso 1 del protocolo de diagnóstico (releer todo)
- Después de cada edición: verificar que no quedan bloques `@media print` duplicados

---

**Diagnóstico de colores que no se imprimen — checklist en orden de probabilidad:**
1. `print-color-adjust: preserve` en vez de `exact` (causa más frecuente)
2. JS `IntersectionObserver` dejando `opacity: 0` en elementos (leer script.js primero)
3. `background: none` en selector agrupado que incluye el contenedor con fondo
4. Bloques `@media print` duplicados en conflicto
5. `linear-gradient` — usar `background-color` sólido en `@media print`
6. Animación de carga (`body.style.opacity = '0'`)
7. El usuario debe activar "Gráficos en segundo plano" en el diálogo del navegador
