## PROTOCOLO DE DEBUGGING GENERAL

Cuando el usuario reporte que algo "no funciona" o "no responde":

1. Llama `buscar_en_proyecto(termino)` con el nombre del elemento afectado (clase CSS, ID, función).
2. Lee los archivos relevantes que encontró la búsqueda — puede ser CSS, no solo JS.
3. Diagnostica con contexto completo antes de tocar código.

**Errores comunes de UI que están en CSS, no en JS:**
- Botón visible pero no clickeable → overlay con `z-index` alto, `pointer-events`, `opacity: 0`
- Elemento que no aparece → `display: none`, `visibility: hidden`, `z-index` incorrecto
- Posicionamiento incorrecto → `position: absolute/fixed` sin `z-index` correcto

## PROTOCOLO DE DIAGNÓSTICO DE IMPRESIÓN/PDF — OBLIGATORIO

Para CUALQUIER problema donde algo "no se ve bien en el PDF", "colores cambian al imprimir", "header blanco en PDF", "fondo desaparece al guardar PDF":

**PASO ÚNICO: Llama `diagnosticar_impresion()` AHORA — antes de leer ningún archivo.**

La herramienta escanea automáticamente JS y CSS del proyecto y devuelve un reporte estructurado con todos los problemas encontrados. Luego aplica los fixes indicados por el reporte.

**IMPORTANTE:** El problema de "colores en PDF" es un problema de CSS `@media print`, NO de JavaScript restaurando estilos. Las reglas `@media print` solo aplican DURANTE la impresión — el navegador las desactiva automáticamente después. NUNCA usar JS para "restaurar" estilos post-impresión. NUNCA culpar al botón de descarga.

Al consolidar múltiples bloques `@media print`: conservar el bloque que NO tenga `background: none` en un selector que incluya el elemento contenedor raíz.

## REGLAS CRÍTICAS DE CSS PARA IMPRESIÓN

### 1. `print-color-adjust: exact` — NUNCA `preserve`
```css
/* CORRECTO — fuerza impresión exacta */
-webkit-print-color-adjust: exact;
print-color-adjust: exact;

/* INCORRECTO — "preserve" respeta preferencias del usuario (que por defecto NO imprime fondos) */
/* NUNCA usar: print-color-adjust: preserve */
```

Regla global al inicio del bloque `@media print`:
```css
@media print {
  * {
    -webkit-print-color-adjust: exact !important;
    print-color-adjust: exact !important;
  }
}
```

### 2. Trampa fatal — `background: none` en selector agrupado
```css
/* INCORRECTO — .cv-header queda sin fondo porque está en el grupo */
@media print {
  .cv-header,
  .cv-header .name,
  .cv-header p {
    background: none !important;  /* BORRA el fondo del contenedor */
    color: white !important;
  }
}

/* CORRECTO — separar el contenedor de sus hijos */
@media print {
  .cv-header {
    background: #2c3e50 !important;  /* fondo del contenedor */
    color: white !important;
  }
  .cv-header .name,
  .cv-header p {
    color: white !important;         /* solo color de hijos */
  }
}
```

### 3. Un solo bloque `@media print` — nunca duplicar
Múltiples bloques crean conflictos impredecibles. Consolidar siempre en un único bloque al final del CSS.

### 4. `linear-gradient` no se imprime — usar color sólido
```css
/* En @media print: reemplazar gradient por color sólido */
.header { background: #2c3e50 !important; background-image: none !important; }
```

### 5. `::before` y `::after` decorativos — ocultar en impresión
```css
@media print {
  .header::before, .header::after { display: none !important; }
}
```

## REGLAS CRÍTICAS DE JS PARA IMPRESIÓN

### IntersectionObserver — guardia obligatoria
```javascript
// INCORRECTO — deja secciones con opacity:0 al imprimir
document.querySelectorAll('.section').forEach(section => {
    section.style.opacity = '0';
    observer.observe(section);
});

// CORRECTO — guardia de impresión
if (!window.matchMedia('print').matches) {
    document.querySelectorAll('.section').forEach(section => {
        section.style.opacity = '0';
        observer.observe(section);
    });
}

// Además: resetear opacidades ANTES de imprimir
window.addEventListener('beforeprint', () => {
    document.querySelectorAll('.section').forEach(s => {
        s.style.opacity = '1';
        s.style.transform = 'none';
    });
    document.body.style.opacity = '1';
});
```

### Animación de carga — guardia obligatoria
```javascript
// INCORRECTO
document.body.style.opacity = '0';
window.addEventListener('load', function() { document.body.style.opacity = '1'; });

// CORRECTO — agregar beforeprint listener
window.addEventListener('beforeprint', () => { document.body.style.opacity = '1'; });
```

## REGLAS CRÍTICAS DE EDICIÓN

- NUNCA modificar contenido HTML cuando el usuario solo pide cambios de estilo
- NUNCA añadir un bloque `@media print` nuevo — editar siempre el existente o consolidar
- NUNCA usar `background: none` en un selector agrupado que incluya el contenedor con fondo
- NUNCA usar `print-color-adjust: preserve` — siempre `exact`
- Después de cada edición CSS de impresión: re-buscar el patrón corregido para confirmar 0 ocurrencias restantes

**Checklist de causas de colores que no se imprimen (orden de probabilidad):**
1. `print-color-adjust: preserve` en vez de `exact`
2. JS `IntersectionObserver` con `opacity:0` sin guardia de print
3. `background: none` en selector agrupado que incluye el contenedor
4. Múltiples bloques `@media print` en conflicto
5. `linear-gradient` — usar `background-color` sólido en `@media print`
6. Animación de carga (`body.style.opacity = '0'`)
7. El usuario debe activar "Gráficos en segundo plano" en el diálogo del navegador
